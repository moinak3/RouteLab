## Judgment calls

- Keep Benchmarking's Astra, Sol and Opus models and add them to the shared catalog, because those named models are central to the existing interview demo.
- Treat the stored traces as a deterministic representative sample. The generator stores monthly-call representation explicitly; all monthly economics use that factor rather than a fixed 30-day multiplier.
- Keep RouteLab's signed-policy work and reshape it into the requested Policy pages rather than discard it.
- Keep the DeepSeek sponsored evaluation panel unchanged except for inherited global typography, tokens, formatting and shared economics.
- Use Inter Variable and DM Mono as local npm assets. No runtime font request is required.
- Overview economics use every eligible catalog candidate. The sponsored panel remains scoped to its disclosed candidate set.
- Unit costs below one cent render with sufficient precision to avoid a misleading `$0.000` value.
- The before screenshots use commit `4379928`, the final pre-cleanup application state. Pages introduced by this redesign map to the closest historical screen for comparison.
- The computed-style audit is the source of truth for typography and color limits. A final CSS enforcement layer keeps legacy page styles within the shared token system while preserving their layouts.
- Workstreams 2 through 5 landed in a consolidated feature commit and production-compatibility follow-ups because a previously delegated cloud task advanced the same branch. The published history was not rewritten.
