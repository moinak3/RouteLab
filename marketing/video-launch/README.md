# RouteLab explainer launch kit

The canonical 90-second video is hosted in Vercel Blob for the RouteLab marketing site. Upload the same 16:9 master natively to YouTube and X. Use either the 16:9 master or the 4:5 social cut for LinkedIn.

## Assets

- `routelab-explainer-90s-v2.mp4`: 1920x1080 master for YouTube, X, and the website
- `routelab-explainer-90s-v2-linkedin-4x5.mp4`: 1080x1350 social cut for LinkedIn
- `routelab-explainer-v2-poster.png`: thumbnail source
- `routelab-explainer-90s-v2.srt`: optional caption file

The video already has open captions. Do not enable an uploaded caption track by default unless the open-caption master is replaced with a clean master.

## Publishing order

1. Publish the 16:9 master to YouTube as a public video.
2. Add the YouTube title, description, and thumbnail in `youtube.md`.
3. Upload the 4:5 cut natively to LinkedIn with the copy in `linkedin.md`.
4. Upload the 16:9 master natively to X with the copy in `x.md`.
5. Keep the website embed pointed at Vercel Blob rather than YouTube so the marketing page remains fast and visually controlled.
