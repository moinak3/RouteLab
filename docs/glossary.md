# RouteLab glossary

| Concept | Product term |
| --- | --- |
| A recurring kind of request | Task |
| Human-labeled ground truth | Golden dataset |
| Judge versus human comparison | Calibration |
| Minimum task pass rate for an override | Quality bar |
| Per-trace judge cutoff | Judge pass threshold |
| Classifier confidence cutoff | Confidence threshold |
| Share of traces scored by the judge | Judge coverage |
| Share of tasks with golden rows | Golden coverage |
| Approved routing rules | Policy |

"Task signature" may be used only in technical documentation or tooltips, not as a navigation or page label.
